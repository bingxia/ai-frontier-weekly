# AI 周报｜2026-11-02—2026-11-08

## 摘要

本期聚焦 Agent 工程：依赖更新进入标准软件流程，跨 IDE 协作采用协议接入，研究则尝试自动优化推理策略和真实工作数据。以下为核验后的精选，不代表完整新闻覆盖或热门排名。“工程启示”均为编辑分析；论文数字为作者报告，未独立复现。核验日期：2026-11-09。

## 一、行业 / 模型与产品动态

### 1. Dependabot 支持 Agent Package Manager
- **日期：2026-11-03。**
- **事实：** Dependabot 可为 apm.yml 中受支持的 Git 依赖创建版本更新 PR，并在存在锁文件时重新生成 apm.lock.yaml。支持范围是版本更新，不是安全更新。
- **关注价值：** Skills、提示词和指令开始进入可审查的依赖升级流程。
- **工程启示：** 将 Skill 更新 PR 接入任务回放、权限差异和成本回归检查；版本更新成功不代表行为安全。
- **来源：** [GitHub 官方公告](https://github.blog/changelog/2026-11-03-dependabot-version-updates-support-agent-package-manager/)。

### 2. Copilot 接入 JetBrains Air
- **日期：2026-11-03。**
- **事实：** 集成采用 Agent Client Protocol（ACP），支持 IDE 内和云端任务。云任务使用新虚拟机上的 Docker 容器，流量经过代理，任务之间不保留状态。
- **关注价值：** Agent 与开发界面的连接开始协议化，执行环境也成为明确的产品边界。
- **工程启示：** 分开设计客户端协议、执行沙箱和计费观测；跨平台接入时验证取消、恢复、文件变更及身份传递。
- **限制：** 官方说明 Air 的分析不包含 Copilot 使用情况，管理员也不能在 Air 内设置 Copilot 支出限额。
- **来源：** [GitHub 官方公告](https://github.blog/changelog/2026-11-03-github-copilot-is-now-available-in-jetbrains-air/)。

## 二、论文与技术趋势

### 1. Strategist：把推理策略沉淀为可执行蓝图
- **日期：2026-11-02 首次提交；核验为 v1。**
- **事实：** 元 Agent 检索既有策略蓝图，生成候选代码，在开发样本上测试并修订，再纳入可复用库。作者在 30 个基准上报告平均准确率 74.7%，对照为 74.0%，推理成本降低 39%。
- **关注价值：** 优化对象从模型权重扩展到模型调用之间的推理程序。
- **工程启示：** 将候选策略作为版本化代码，使用独立留出集验收；同时核算策略搜索成本与后续推理节省，避免只看运行阶段成本。
- **限制：** 本期仅核验论文，不将其列为已核验开源实现；跨任务迁移结果不能直接推广到生产工具链。
- **来源：** [Strategist](https://arxiv.org/abs/2611.03618)。

### 2. Agent-R²：从真实文件和工作需求合成训练任务
- **日期：2026-11-05 首次提交；核验为 v1。**
- **事实：** 研究从一万个候选中筛选四千个任务，将真实多格式附件与交付物评分规则配对，通过 SFT 和基于评分规则的 RL 训练 4B 模型。作者报告 GDPval 得分 51.0%，OfficeQA 为 14.8%。
- **关注价值：** 办公 Agent 的训练目标进一步转向可用交付物，以及充分读取、构建和验证文件的过程。
- **工程启示：** 构造文档、多模态办公任务时，应保留真实文件结构，分别验收事实依据、格式、计算结果和可打开性。
- **限制：** 低参数模型在这些设置下的结果不代表通用能力超过大型模型；本期未确认完整代码和数据开放状态。
- **来源：** [Agent-R²](https://arxiv.org/abs/2611.08219)。

## 三、开源项目

### Microsoft APM：因本周 Dependabot 接入而重新关注
- **日期：相关生态更新为 2026-11-03；仓库核验为 2026-11-09。**
- **事实：** 这是既有项目，并非本周首次发布。公开仓库包含 Python CLI 源码、测试、安装脚本和 MIT 许可；以清单和锁文件管理 Agent 上下文依赖。已读取源码文件，确认不是只有介绍页。
- **关注价值：** 同一组指令、Skills 和配置可以形成可复现的依赖集合，本周新增的 Dependabot 支持补齐了更新入口。
- **工程启示：** 优先借鉴清单、锁定版本、依赖树和升级 PR；对提示词行为变化增加任务级回归，不能仅依赖包完整性校验。
- **限制：** 未执行安装或运行测试；主项目许可不自动覆盖所有依赖。无可核验周增长数据，不称热门榜单。本期只保留这一项已核验代码项目，避免将论文或代码承诺凑成开源清单。
- **来源：** [APM 仓库](https://github.com/microsoft/apm)、[源码](https://github.com/microsoft/apm/blob/main/src/apm_cli/__init__.py)、[许可](https://github.com/microsoft/apm/blob/main/LICENSE)。
