# AI Frontier Weekly｜AI 前沿周报

用于收集 AI 前沿消息，按周归档模型与产品动态、论文与技术趋势，以及值得关注的开源项目。

## 内容原则

- 优先一手来源，保留事件日期、论文或项目原始链接。
- 每条说明发生了什么、关注价值和工程启示。
- 区分作者报告、已核验事实与编辑分析；不将宣传指标视为独立验证。
- 不发布个人隐私，不编造热度排名，不将既有项目误标为本周新发布。
- 本仓库为信息整理与学习参考，重要选型请进一步查阅原始资料。
